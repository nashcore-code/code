# Nash core computational code

This repository contains two computational components:

- [`heuristics/`](heuristics/) — the original heuristic implementation and notebook.
- [`discrete-core-nonemptiness/`](discrete-core-nonemptiness/) — the exact computational artifact for discrete-core nonemptiness with at most eight voters.

See the README in each directory for installation, data, and reproduction instructions.
