- `positive_antichains_m4_m6.txt`: positive-dual antichains with `m=4,5,6`.
- `positive_antichains_m7.txt`: positive-dual square antichains with `m=7`.

- `puncture_certificates.json`: explicit singleton punctures used by the square
  and rectangular separation verifiers.
