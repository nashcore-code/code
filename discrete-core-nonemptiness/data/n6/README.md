  `m=4,5,6`.
- `final_cells.txt`: the 46 cells retained for final exact classification.
- `bad_cells.empty`: canonical empty output for bad tight/boundary cells.
- `surplus_cells.empty`: canonical empty output for all-surplus cells.

All 46 final cell records are coordinatewise-minimal (`P` records).
